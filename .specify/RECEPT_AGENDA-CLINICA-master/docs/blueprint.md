# **App Name**: AgendaWise

## Core Features:

- Metrics Dashboard: Display key metrics via cards, including total appointments today, this week, this month, and room occupancy rates.
- Interactive Calendar: Provide an interactive calendar with monthly, weekly, and daily views. Use color-coding to differentiate event types.
- Appointment List: List appointments in a detailed table, including date/time, title, status and room/resource. Provide filtering by period, user, status, and room.
- Appointment Form: Implement a form for creating and editing appointments, including title, description, date/time, participants, and resource selection.
- Notifications and Alerts: Show banners or modals for critical events like scheduling conflicts.
- Reporting Dashboard: Display visual performance indicators for reporting and analytics

## Style Guidelines:

- Primary color: Slate blue (#708090) for a professional and calming interface.
- Background color: Light gray (#F0F8FF) for a clean and neutral backdrop.
- Accent color: Muted gold (#B8860B) for highlights and important actions, providing sophistication.
- Body font: 'Inter', a grotesque-style sans-serif font. Headline font: 'Space Grotesk'. 'Inter' is recommended for body text in longer text blocks and 'Space Grotesk' is for headlines
- Use clear, consistent icons from a set like Material Icons to represent different types of events and actions.
- Employ a responsive layout that adapts to different screen sizes, ensuring usability on both desktop and tablet devices.
- Use subtle transitions and animations to enhance user experience when navigating between views or interacting with components.
